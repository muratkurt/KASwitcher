# KASwitcher

Close all apps at once, hide apps in a locked vault, pin the ones you keep.

## Install

Add `https://muratkurt.github.io/` in Sileo and install **KASwitcher**. Needs PreferenceLoader.

## Requirements

- iOS 16 or later
- RootHide or rootless

## Features

- **Close all** — tap the X in the app switcher; undo during the countdown. Hold the X for the menu.
- **Vault** — swipe a card down to hide the app; open the vault with Face ID.
- **Pin** — hold a card in the vault; pinned apps are skipped by Close All.
- **Protect** — music, maps and apps you choose are never closed.
- **Auto close** — apps unused for 1–12 hours.
- **10 themes**, 12 languages.

**Move the X button:** hold the X › **Settings** › **Move Button**.

Details and changelog: [package page](https://muratkurt.github.io/depictions/com.muratkurt.kaswitcher.html).
